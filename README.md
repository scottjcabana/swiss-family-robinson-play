# Swiss Family Robinson: Castaways of New Switzerland

A 1990s Sierra-style adventure game of the full story of *The Swiss Family Robinson*:
18 chapters following the book, from the shipwreck to the English ship.

**Play it:** https://scottjcabana.github.io/swiss-family-robinson-play/

The whole game is one file (`index.html`). It runs in Chrome, Edge, Firefox or Safari with
nothing to install, and saves stay in your own browser.

How to play: move the mouse to the top of the screen for the icon bar (Walk, Look, Hand,
Talk, Item). Right-click cycles the verbs. Type a command like LOOK AT TREE and press Enter.
Mother gives hints. F4 opens Father's Journal, F5 saves, F7 restores, Esc opens the controls.

After the novel by Johann David Wyss (1812), in the English translation by W. H. G. Kingston
(1879), both in the public domain.
